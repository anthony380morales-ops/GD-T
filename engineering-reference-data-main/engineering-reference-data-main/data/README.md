# data/

CSV is the source of truth. JSON files are generated by `tools/to-json.py` and
must match; `tools/verify.py` fails if they drift.

## gdt-symbols.csv

14 geometric characteristics.

| Column | Meaning |
|---|---|
| `characteristic` | English name as used on drawings |
| `category` | `form`, `profile`, `orientation`, `location`, or `runout` |
| `datum_required` | `no` for form, `optional` for profile, `yes` otherwise |
| `symbol` | The Unicode character itself |
| `codepoint` | `U+XXXX` form |
| `unicode_name` | Official UCD name; must match `unicodedata.name` |
| `codepoint_dedicated_to_gdt` | `yes` if the UCD name *is* the engineering term |
| `asme_y14_5_2018` | `active` or `withdrawn` (concentricity and symmetry only) |
| `iso_1101` | `active` for all 14 rows |

## gdt-modifiers.csv

15 material-condition and drafting modifiers. Same Unicode columns as above.
`note` is empty except where ASME practice has changed (RFS).

## surface-roughness-grades.csv

ISO 1302 preferred Ra numbers for N1–N12. N9 is 6.3 µm, not 6.4; N7 is 63 µin,
not 64. N-grades are not used in ISO 21920-1:2021. This file is not an Ra↔Rz
table.
